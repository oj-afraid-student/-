# 知序 · 高中数理学习助手

当前版本：HTML 展示原型 V0.1。

本仓库保存现阶段的前端展示界面、可编辑源码、虚构演示数据和配套截图资料，便于小组体验、协作修改及撰写需求报告。

## 直接体验

下载仓库并解压，用 Edge 或 Chrome 打开根目录的 **index.html** 即可。HTML 已内嵌脚本、样式和数据，不需要安装依赖或启动服务器；单独分享这个 HTML 文件也可以体验。

GitHub 文件页面显示源码；体验时请下载后打开。各浏览器的演示记录分别保存在本地，不会在组员之间同步。

推荐路径：学习主页 → 知识分析 → 题目重构 → 条件确认 → 物理实验室 → 个性化练习 → 测验反馈；随后体验立体几何和教师端的审核、发布及班级反馈。

详细操作见[使用说明](使用说明.md)。

## 当前展示内容

- 题目文字与题图输入、条件核对及异常场景。
- 水平面单物块分阶段运动仿真、受力和图像联动、参数比较。
- 正方体旋转、投影与线面关系探索。
- 根据演示作答记录计算知识点指标、组织练习、判题和订正。
- 教师候选题审核、本地任务发布与班级反馈。

这是本地交互原型。图片识别、资料理解和 AI 生成采用预设场景；角色切换不是真实认证。当前没有后端数据库、真实账号权限、跨设备同步或真实 AI 服务。人物、班级和作答记录均为虚构。

## 修改与重新构建

修改 `src/` 或 `data/` 后，在仓库根目录运行：

```sh
python build.py
```

随后重新打开 `index.html`。仅体验页面不需要 Python。重新构建时应将更新后的源码、数据和 `index.html` 一起提交。

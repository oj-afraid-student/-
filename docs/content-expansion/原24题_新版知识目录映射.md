# 原有 24 道题的新版知识目录映射

采用穆泓烨 PDF 第 1–2 页的分类。SG-01 收基础空间位置关系，SG-03 收直线位置关系专项，SG-04 收线面与面面关系的判定和性质。距离、角度和体积按题目真正所求归入对应单元。综合题可同时关联多个单元。

以下 knowledgeIds 和 unitIds 是新版目录中的目标编号。unitIds 逐题由细分知识点的单元归属推出并去重。题号、题干和答案沿用现有平台的 Q01–Q24。

- 对知识网络来说，新版目录更清楚。SG-01 负责概念总览，SG-03 负责直线专项，SG-04 聚合判定与性质。原版的有效资产是已发布题目、解析和历史答卷。

- PDF 的 SG-07 未列细分点。Q20 采用上一份扩充标注补出的 G7-02「截面周长、面积与极值」。
- PDF 的拓展单元列了圆锥曲线和翻折。原版的 E3「空间向量」仍用于 Q23 和 Q24，建议作为拓展保留。

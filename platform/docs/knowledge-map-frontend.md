# 知识图谱前端（2026-11-16）

基线：feature/practice-v2-storage 的 72e541e，包含同事已合入的知识服务。当前按用户确认的效果图制作独立 /knowledge-map 页面；本轮不填入真实学科知识。

## 本轮交付

- 桌面工作区左图谱、右题目为 2:1；右侧底部固定留出 AI 对话区域。小于 760px 时改为上下排列。
- 最高层初始居中，点击任意相邻圆圈切换中心；上级位于上方，下级占用剩余等角方位。节点半径与间隔按邻居总数计算；节点密集时扩大布局并自动适配视野。
- 保留稳定节点 DOM 和 ID，使用 650ms 缓动移动、缩放节点及连线。切换期间可以继续选择目标；离场节点立即隐藏，避免叠影。系统偏好减少动态效果时关闭过渡。
- 拖动平移、放大/缩小、复位、返回总览、面包屑回溯、浏览器前进/后退和刷新保留节点。原生按钮可通过键盘操作，隐藏节点不进入 Tab 序列。
- 右侧上下文随中心节点更新。题目、上传题、知识详情与 AI 功能当前有明确待接入状态，相关按钮禁用，不创建虚构题目、回答或上传成功状态。
- 数据加载、失败重试、空目录和末级节点均有独立状态；坏目录在布局之前拒绝。

## 后续内容接入

`src/features/knowledge-map/graph-model.ts` 定义本功能内部的 GraphStructure / GraphNode，不修改共享业务 DTO。

- `id`：稳定编号；`label`：节点名称；`parentId`：上级编号，总览为 null。
- `detailHref`：后续由目录适配器提供的知识详情入口；缺少时禁用详情。
- `placeholder`：是否使用占位结构；正式目录接入后设 false。
- `structure.ts` 只提供四层通用占位节点，没有数学概念或真实题目标签。取得同学的数据后，用统一业务请求替换 loadGraphStructure；不要在页面里直接访问数据库或完整答案题库。
- 图谱点击、居中及渲染不依赖知识接口结构；KnowledgeMap 的 loader 参数支持独立适配及异常走查。目录必须只有一个根，不能重复编号、缺父节点或形成循环。

按细分知识点取题仍需对应目录编号与查询接口。当前 v2 的 FILTERED.knowledgePointId 是单元编号，不能擅自把细分节点 ID 塞入该字段。题目标签查询、上传题知识链定位/高亮、仿真入口与 AI 对话作为后续接入项，本轮没有新建或伪造业务 API。

## 本轮验证与边界

- pnpm check 通过：45 项测试（原 42 项保留，新增图谱 3 项）、类型检查、生产构建。上游目录服务及集成测试存在 4 条既有未使用变量警告，未放宽规则或修改他人文件。
- 图谱测试覆盖四级父链、末级、1—32 个相邻节点的等角与安全间距，以及重复 ID、缺父、循环、多根、空目录。
- 内置浏览器在 1440×960 验证实际左右宽度比恰为 2、无横向溢出；四级下钻/返回、上下文联动、六个下级节点、115% 缩放与复位、70×45px 拖动、刷新保留当前节点均通过。
- 390×844 验证无横向溢出，右栏改为下方，未接入的 AI 输入保持禁用。恢复默认浏览器尺寸，预览页保留供用户体验。
- 客户端边界检查通过：无私有答案规则、禁止导入或禁用界面文案。

真实图谱内容尚待同学提供；未把既有知识目录或爬取数据自动映射为本轮图谱。当前可验证的是结构、布局与交互，不能视为真实图谱关联题或 AI 联调已完成。

# 本轮范围与首日交接

依据：团队原需求规格说明书、本轮助教“先数学、先学生最小可用流程”的建议，以及已确认的三周分工。数学首批内容按团队最新决定改为立体几何。原文档范围更广的 V1 不等于本轮必达版本。

## 三周必达

学生注册登录 → 选择三个单元之一 → 阅读知识与配图 → 完成五道单选练习 → 服务端判题并保存 → 刷新、重登回看本人结果。

错题筛选为核心验收通过后的选做。教师、班级、资料管理、AI、物理、三维旋转、自动辅助线、证明题批改、空间向量及复杂角距计算延后。

## 首日工程已经提供的能力

- 独立工程、固定版本、别名、Tailwind、严格类型与格式规则。
- 最小首页与真实 health 接口的联通检查。
- 服务端成功/失败封装，数据库延迟连接与事务工具。
- 明确未实现的认证守卫；没有虚构登录状态。
- 数据库迁移、种子命令、约束与回滚验证。
- 模块目录、维护归属、接口基线、协作规则和 CI。

账号、课程、练习、结果、历史业务页面与 11 个业务接口由对应负责人按任务继续实现。没有把根目录已有展示逻辑迁入正式工程。

## 首日与三周验收区分

首日：全组从同一提交拉取，按 README 启动；首页和 health 联通；检查与构建通过。数据库测试在 PostgreSQL 引擎的内存测试环境验证，不代替真实服务器部署验证。

三周：注册新账号，五题故意答错两题得到 3/5；解析一致；刷新、重登后可回看；重复提交不重复保存；换账号不能读取前一用户数据；题干与图形一致。以上业务验收在对应模块实现后执行。

# AI 提示、候选练习与模拟组卷验收

## 组员配置

每位组员在自己的 `platform/.env.local` 填入以下配置。密钥需在并行科技平台取得，并有权调用所填模型。

```dotenv
ZHIXU_AI_BASE_URL=https://llmapi.paratera.com
ZHIXU_AI_MODEL=DeepSeek-V4.1-Flash-1017
ZHIXU_AI_API_KEY=
```

共享联调环境由维护者在服务端配置组内授权的密钥，组员通过网页调用，无需各自填写。密钥仅存本机环境文件或共享服务的密钥配置，勿放到 Git、群消息和截图中。保存后重启服务。若平台返回 HTTP 403，请为当前团队和密钥开通对应模型权限。照片转录还需模型支持图片输入。

在 `platform/.env.local` 设置 `ZHIXU_AI_BASE_URL`（兼容 OpenAI Chat Completions 的 API 根路径，例如提供方的 /v1）、`ZHIXU_AI_MODEL` 和 `ZHIXU_AI_API_KEY`。模型需支持 JSON object 响应。服务端调用入口为 `src/server/ai/model.ts`，图像识别可传入文本和 image_url 内容。配置密钥仅放在服务端环境文件。模型请求最长 45 秒，页面最多等待 55 秒，失败由用户显式重试。

按数据库说明迁移并导入正式题库，关闭开发样例并使用真实账号。

1. 创建包含 Q24 的练习，在第二或第三小问填写部分推理后点击该问的“给我一个下一步提示”。检查提示针对该问和已有步骤，且没有给出最终答案。切题时检查上一题的提示随页面清除。提交后从结果页查看完整解析。
2. 自主练习 → AI 候选练习。选择现有小知识点、难度及题型。核对候选题、答案、解析和标签，勾选后可导出 JSON。下载件仍为待复核，供题库负责人按现有内容格式整理、复核并纳入 `db/content-release.json`，再通过 `pnpm db:import-content` 发布。学生端没有发布权限。
3. 自主练习 → 模拟组卷。选择知识单元、难度及题量，组卷后作答并提交。确认结果页提供参考答案与解析。选择题量大于匹配数时应显示不足原因。
4. 使用无效模型配置检查错误提示，并在修正配置后重试。检查不符合题型约束的候选输出被拒绝。用第二个账号访问同一练习时不能获取提示。
5. 用支持图片输入的模型，在大题的小问下拍照或上传该问的手写过程。核对并编辑识别文字，点“用识别文字替换本小题作答”。确认只有该问的输入被替换，刷新后文字随草稿恢复。照片只用于本次转录，答卷保存文字。

## geometry-content-v2 联调

### 在线复核发布

1. 用已注册的复核员账号登录正式模式，在浏览器打开 `/api/v1/auth/me`，复制返回的 `data.id`。
2. 将这些账号 UUID 用逗号分隔填入服务器的 `ZHIXU_QUESTION_REVIEWER_IDS`，重启服务。空配置时没有账号可发布。
3. 进入“自主练习 → AI 候选练习”。生成后可编辑标题、题干、选项或小问、答案、解析、难度及正式知识点。选择题答案使用从 1 开始的选项序号，每行一个。
4. 确认题目和解析后点击“确认并导入题库”。页面会显示分配的正式题号，可在指定题号练习中验证。扩充预览标签要先进入正式目录，或改选实际匹配的正式知识点。

在线发布结果保存在当前 PostgreSQL 数据库，带复核员 ID 和发布请求标识。重复请求不会生成第二道题。它不修改静态发布清单，迁移到其他环境时需迁移数据库内容。审核确认由人工完成。

AI 候选入口读取扩充目录中的 15 个单元和 39 个细分知识点。尚未导入正式目录的小知识点标为“扩充预览”。选一个扩充预览点生成并核对，导出件仍为待复核。目录快照只包含编号和标题，更新时与标注交接数据同步。

模拟组卷支持按单元或正式细分知识点筛选。只取数据库中已发布且标签匹配的题目。标注交接里的 62 道新增题尚未进入发布清单，需按原有复核及版本规则正式导入后才会进入练习和组卷。旧答卷继续引用固定题目版本。

## 来源及同步

上游资料：仓库根 docs/content-expansion/立体几何扩充_标注数据.json 的 directory、questions，以及 platform/fixtures/content/questions.json 的旧 24 题公开版本。

交接目录采用兼容正式平台编号的方案：SG-02 仍是线面平行，SG-03 仍是线面垂直，几何体使用 SG-11。不采用另一份 Markdown 中会与已发布标签冲突的 PDF 目标编号，不重写历史题目、答案快照或数据库。

生成命令（platform 下）：

```sh
node scripts/build-knowledge-map-content.mjs
pnpm exec prettier --write public/content/geometry-knowledge-map.json
node scripts/build-knowledge-map-content.mjs --check
```

生成器按字段白名单产生 public/content/geometry-knowledge-map.json，格式兼容统一 request 的响应信封。它是公开教学资料快照，静态地址可以直接读取，不承载账号、个人数据、参考答案、推导笔记或判题配置；图谱页面继续由现有学生登录守卫保护。浏览器只请求这个文件，不直接导入服务器题库或原始带答案标注。更新内容后重新生成；自动测试会检查生成结果与来源一致、所有知识引用有效、所有图片实际存在。

## 开发 HTTP 验证

在显式开启 ZHIXU_DEV_FIXTURES=1 的 pnpm dev 上执行 node --test tests/frontend-integration.mjs，通过一项完整闭环测试，包含：

- 注册成功不创建会话；重复用户名 409；密码首尾空格保留；登录与退出行为正确。
- 六单元、24 题、八题型，未提交响应无参考答案与判题规则。
- 漏题及 Q14 少一个值返回 400，原练习仍为 OPEN。
- 提交首次 201，相同内容按题项、多选与无序值重排后重试 200，返回同一 submissionId；修改答案返回 409。
- 标准答案样例为已判 11、已判正确 11、待复核 13、score=null；未枚举填空表达式进入待复核。
- 客观题故意答错时产生 INCORRECT，全部判完后才有总分。
- 历史分页、越界空页、非法分页参数、显式题序、筛选题量不足、退出重登与双账号 404 隔离符合契约。
- 开发适配不接管 /api/v1。

这些结果仅说明开发适配及前端对契约的理解一致，真实业务仍待相应服务负责人实现。

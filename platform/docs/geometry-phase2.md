# 通用几何场景与图文理解

本轮将新题入口从两种固定模板改为声明式构造协议。默认界面保持「原图和题设 → 条件核对 → 构造方案 → 三维视图 / 参数 / 量测 → 场景提示」。场景数据决定点名、参数数量和范围、量测项目，不生成任意 HTML 或执行模型代码。

## 图片理解

图片识别额外输出 diagram：图示关系、来源类别（文字标注、几何符号、连接关系或不确定）及可核对的依据。明确关系进入 conditions，模糊关系进入 uncertainties。用户进入实验室时压缩后的题图与文字一起保留在当前标签页 sessionStorage；实验室显示题图，并在生成场景时再次发送给 DeepSeek。照片不进入 Git 或数据库。原始高分辨率文件未持久化，最大边1800的预处理图用于后续理解。刷新实验室可恢复同一任务；关闭标签页后不可恢复。

## 受限但可组合的构造语言

支持最多3个参数、32个点、64条边、16个凸三角形或四边形面。

- 固定点坐标。
- 边上点：端点与线性比例；不同点共享参数可表达比例联动。
- 任意轴旋转：原点、轴与角度；共享轴角表达刚体折叠。
- 点到三点确定平面的垂足。
- 量测：点点距离、点面距离、两直线夹角、点到无限直线距离。
- 独立数值检查：长度、比例、平行、垂直。

参数由有限数值或参数的线性函数给出。禁止表达式代码、循环、任意函数。引用须按依赖顺序，重复ID、未知引用、越界参数、退化方向、自交或不共面面片均拒绝。

验证：初始状态与每轴5点的笛卡尔积（最多125组）检查；每次用户调节参数重新检查，不满足约束时保持前一状态。采样不能证明整个连续区间，条件引用覆盖也不能证明自然语言的语义等价。界面明确保留这些边界；遗漏条件或模型自述限制会标为示意模型。无独立约束也标为示意。不得把数值探索当成最大值或证明题的结论。

## 通用UI

参数滑杆按协议自动生成；角度内部为弧度，显示为度。三维坐标仅在绘图时适配视野，数学量测保留原尺度。空间 / 俯视 / 正视切换、面透明度、双点量测、辅助线与撤销、恢复初始状态均可用于不同构型。渲染器不再无条件引用A/B/C/D或显示固定垂足H。

AI提示接口重新计算真实参数下的坐标、量测及残差，附带当前分问、选中点及思路发送给DeepSeek，不信任浏览器提供的计算结果。场景变化清除旧提示。

## 仍不覆盖

非线性约束求解、任意曲面、圆锥曲线、复杂多体机构、通用数学证明和全局极值求解。图片关系仍可能识别错误，必须核对原图。模型失败时拒绝显示错误构型，允许修正条件或重试。未声称支持所有高中题。

## 验证入口

`tests/universal.test.mjs` 覆盖矩形动点比例联动、沿可动轴旋转、刚体长度与距离、非法引用与表达式拒绝。测试中E在AB、F在DC是明确给定条件，不代表已确认用户原题的这两条边。

`tests/universal-live.mjs` 是显式付费API验收，不纳入普通测试；使用当前服务端DeepSeek配置。`tests/universal-browser.mjs` 回放模型返回以确定性验证桌面/手机的选图、传图、导航、WebGL和辅助线，不能当作真实AI端到端质量评测。

## 可组合的高中几何 skill 库

`src/features/geometry/skill-library.ts` 是应用内部的可执行能力目录，不是给 Codex 使用的技能包。目录定义名称、用途、输入协议、输出和前置条件，DeepSeek 在规划时读取目录，通过 `skills` 有序数组组织任务。

目前11项：rectangle、box、midpoint、edge_point、plane_foot、rotate_group、triangle、connect、polygon、prism、pyramid。后三者可组合已有点构成凸面、三/四棱柱、三/四棱锥。基础体自动生成边面和尺寸检查；所有操作统一展开为受限的底层协议，再进行引用、退化、共面、凸性及数值约束验证。技能不执行自定义脚本。

例如本轮测试题（明确假设 E∈AB、F∈DC）：rectangle 建立矩形 → 两次 edge_point 共享参数表达 BE=2DF → rotate_group 同时旋转 A、D → polygon 或 triangle 建立翻折面 → point_line 量测 C 到 A′D′。高层skill和独立底层构造在多个参数下坐标相同；棱柱/棱锥测试覆盖退化高度拒绝。

新增skill的维护流程：先定义输入输出和前置条件，添加确定性展开或求值实现及数学测试，再加入目录提供给规划器。不能只添加提示词就把未实现能力标成可调用。未来可按同样方式添加截面、圆与曲面、复杂约束求解；本轮没有实现这些能力。

真实模型验收记录：DeepSeek确实返回了由skill组成、nodes为空的矩形动点折叠计划，展开后通过25组参数采样；模型同时明确列出未证明/未覆盖项，页面按示意模型展示。测试图片中E/F所在边得到识别，但仍产生待核对项，不能宣称题图理解完全可靠。浏览器回放该真实计划完成1440px和390px界面的图片传递、跳转、WebGL及辅助线操作。

DeepSeek接口默认启用思考时，曾耗尽输出预算而未生成JSON。按[官方接口说明](https://api-docs.deepseek.com/guides/thinking_mode/)对官方DeepSeek端点显式使用非思考模式，并为场景生成配置7000输出token；其他供应商不注入该字段。场景首次校验失败时，最多反馈具体约束和参数重试一次；第二次失败仍拒绝显示模型。不会静默删除约束来通过检查。

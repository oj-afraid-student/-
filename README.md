# 知序学生端 V1.1

沿用 V0.2 的学习空间布局，合入 V1.0 的资料库与题图整理流程，并接入真实注册、登录、服务端判题与个人记录。

## 启动

1. 解压完整项目，电脑需安装 Python 3.10 或更新版本。
2. Windows 双击 **启动知序.cmd**。
3. 等待环境准备完成，浏览器会自动打开 **http://127.0.0.1:8800/**。
4. 首次使用点击“创建学生账号”，注册自己的用户名和密码。

首次启动会在项目内创建 `.venv/` 和 `runtime/`，使用随包提供的离线依赖，无需另装数据库。保持启动窗口运行，按 Ctrl+C 结束服务。

本版有后端，不能再通过双击 HTML 文件使用。不要只发送 `frontend/index.html`，请分享完整压缩包。

也可在项目目录运行：

```sh
python start.py
```

若 8800 端口已被其他程序占用：

```sh
python start.py --port 8801
```

## 当前功能

- 学生用户名与密码注册、登录、退出；密码加密保存。
- 三个立体几何学习单元，包含概念、定理的完整条件、配图与例题。
- 每个知识点固定五题，共十五题；提交前不返回答案，服务端判题后返回正误与解析。
- 本人的练习历史、结果详情、含错题筛选、错题重新练习。
- 原有资料浏览、选择样例题图、核对与入库，资料归属于本人账号。
- 保留三棱柱工作台和板块运动实验室，以及浏览器内保存探索参数。

关键词搜索、掌握度估计、个性化推荐和完整错题管理系统不在本轮范围。学习概览只列出实际练习统计和固定知识结构，不推断学习画像。

## 保存位置

账号、会话、单元阅读状态、题目、答卷和个人入库资料保存在 `runtime/zhixu.sqlite3`。关闭服务后数据仍在。若需备份，先停止服务，再备份整个 `runtime/` 文件夹。

作答提交前的草稿、未入库题图草稿和已保存的模型探索参数，按当前账号保存在浏览器；换浏览器不会带走这些草稿。提交后的练习与入库资料从服务端读取。

题图整理仍采用固定样例和固定解析，不进行真实文件上传、OCR 或 AI 推理。题目图片与解析、几何模型条件一致。

## 开发与验证

后端：Django 5.2.18；数据库：SQLite；前端：HTML/CSS/JavaScript。依赖锁定于 `requirements.txt`，离线 wheel 位于 `vendor/wheels/`。

首次启动后，Windows 可在项目目录运行：

```powershell
.\.venv\Scripts\python.exe manage.py check
.\.venv\Scripts\python.exe manage.py test tests
.\.venv\Scripts\python.exe manage.py makemigrations --check --dry-run
```

初始化单元命令为 `manage.py init_catalog`，可重复执行，不创建固定用户、不重置个人成绩；历史答卷使用题目快照。

源码包不包含测试账号、运行数据库、会话、密钥、虚拟环境或 Python 缓存。此包适用于本机课程开发与验收，启动脚本使用本地开发服务器。

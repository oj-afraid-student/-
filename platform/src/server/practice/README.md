# 练习、判题与记录

主责：王宁岳。五个正式接口已实现，见[交付与验证](../../../docs/practice-handoff.md)。

- `contracts.ts`：服务端版本、发布状态和 catalog 端口。
- `catalog.ts`：002 存储的最小 SQL 适配；只选已发布题，固定内部版本读取，公开字段投影。
- `rules.ts`：三种选题、八题型校验、三态判定和幂等比较。
- `service.ts`：真实事务、归属、提交行锁、去重/冲突、结果与稳定分页。
- `request.ts`：真实会话、同源、JSON/正文限制、统一错误和禁止缓存。

正式服务不导入 fixtures。题库审核、导入和知识接口由赵景言维护，迁移由穆泓烨维护。24题开发样例仍为 DRAFT，测试中发布不等于正式发布。

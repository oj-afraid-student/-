# 本轮范围与交接

当前以《学生端后续开发完整分工表》和[学生端开发交接](student-practice-handoff-v0.2.md)为准，接口以[API v2](api.md)为准。原固定五道单选、三单元十五题计划已被六单元、24题、八题型范围替代；五题3/5保留为确定性判分验收案例，不是产品题量限制。

必达流程：真实注册登录 → 六单元知识学习 → 全部/筛选/指定题号创建练习 → 八题型作答 → 服务端校验、判题与事务保存 → 本人结果和历史回看。主观过程和未枚举填空表达式保留为待复核，总分为空；不承诺自动批改。

核心验证后支持当前结果内错题筛选、错题或整组重练；待复核不算错题。重练创建新练习并保留原结果。完整跨历史错题检索、教师端、物理、上传/OCR、AI、交互模型、画像与推荐延后。

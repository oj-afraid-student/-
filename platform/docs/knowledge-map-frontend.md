# 知识图谱与正式练习

知识图谱分为立体几何、核心或拓展、15 个单元、39 个细分知识点。节点保留等角布局、平滑切换、缩放、平移和面包屑。编排使用 unit:SG-01、point:G1-01 两类编号，避免单元和知识点重名。

## 从图谱进入练习

1. 按 [数据库说明](../db/README.md) 执行迁移和 pnpm db:import-content。内容包含 Q01–Q86，本版发布 85 题，Q33 待复核。原 24 题历史版本继续保留。
2. 登录后打开 /knowledge-map。总览可以创建 85 题整组练习，单元或知识点可以练习该节点关联的题目。按节点与下级知识标签去重，同一个题号在一个节点中只出现一次。
3. 从下拉框选题或切换上一题、下一题，再点「练习此题」。正式练习使用现有 EXPLICIT 接口，作答、提交、解析及历史回看使用同一题目版本。
4. 从结果的「在知识图谱中查看关联知识点」回到该题的一个关联知识节点。图谱链接保存题号和节点，浏览器返回或刷新会恢复选题。若结果中的题已下架，会提示当前没有该关联题，历史答卷照常可查。

Q33 暂缓发布，不加入新建练习。已有答卷继续引用原题版本。正式数据库暂无题目时，图谱显示空题组。练习创建期间遇到下架等变化，按服务端结果提示刷新。整组练习上限沿用原接口的 100 题。

## 数据来源

公开的 public/content/geometry-knowledge-map.json 提供图谱结构、知识正文、配图及既有版本的内容复核标记。实时题干、选项、分问、题目版本与关联标签均来自需要登录的 GET /api/v1/knowledge-map/questions。此接口复用与正式练习相同的已发布版本查询和公开题目投影。参考答案、评分规则只在原有结果流程中使用。开发样例对应使用 /api/development/knowledge-map/questions。

更新图谱目录后，从 platform 执行：

    node scripts/build-knowledge-map-content.mjs
    pnpm exec prettier --write public/content/geometry-knowledge-map.json
    node scripts/build-knowledge-map-content.mjs --check

验证时检查总览 85 题、全部 15 个单元的关联题号、从细分知识点开始作答并返回、换版及下架对历史结果的影响。全量提交可用 tests/practice-integration.mjs，页面链路可用 tests/frontend-real-browser.mjs。两者使用隔离的本机 PostgreSQL 测试库。

## 上传题定位与问答

在「拍照学题」识别并核对题目后，点击「推荐知识点标签」。标签及其依据来自现有推荐接口，使用核对后的题干和分问。勾选要查看的标签后，点击「查看本题涉及知识点在知识图谱中位置」。右侧「关联题目 → 上传题目」列出各命中知识点和它们到总览的祖先链，共享节点只出现一次。左侧保留圆形图谱，上传题知识点和相关上级以青绿色和文字标记区分。点击右侧路径节点可定位到左侧圈图，切换到「知识点题目」可查看公开的关联题目。点击「返回拍照学题」或浏览器后退可回到原来的题图、编辑内容、分问、标签和位置。跳转链接只带知识点编号及当前标签页的临时返回标识。

上传题的复核和入库沿用题库复核入口。图谱 AI 助手可按当前知识点或已选择的已发布题目回应。

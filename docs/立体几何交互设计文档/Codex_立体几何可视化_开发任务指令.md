# Codex 开发任务：AI 立体几何交互实验室

你正在为一个已有的高中学习助手增加“题目拍照 → AI 解析 → 3D 几何可视化及交互”的功能。**请先阅读同目录下《AI_立体几何交互可视化_PRD_技术设计_v1.md》**，该文件是详细需求和数学正确性规范。不要自行省略对几何约束、数值校验和错误降级的实现。

## 第一阶段目标（先完成，暂不必接 AI）
在现有项目技术栈下新增 GeometryWorkbench 模块，完成可运行的正方形折叠 Demo：

1. 正方形 ABCD 边长 4，E 为 AB 中点；将三角形 ADE 沿 DE 翻折，固定底面 EBCD，折叠角 θ 在 0°~90° 变化。
2. 3D 视图支持旋转、缩放、平移、重置镜头；顶点带标签，线段有遮挡/虚线区分；活动面可透明显示。
3. 滑块或折叠手柄控制 θ，折痕 D/E 固定，三角形 ADE 保持刚体；提供折叠前虚影、播放/暂停、复位。
4. 实时显示 A′ 到底面 BCD 的距离和 A′B 长度，支持鼠标点选两点后新建辅助线段，辅助线随运动同步更新。
5. 定义声明式 GeometryScene 数据结构，分开题设约束、场景状态、用户辅助构造；编写几何计算纯函数与单元测试。
6. 用固定 θ 取样测试保证 AD、AE、DE 长度恒定，D、E 坐标不动；遇到退化数值情况要有错误提示而不是 NaN。

## 第二阶段目标（第一阶段稳定后）
1. 接入现有拍照上传和 AI 识别流程，先生成可编辑 ProblemIR，允许学生纠正点名、折痕、已知条件。
2. 实现 Visualization Planner，为不同题型选择 L0~L4 可视化等级；只对已支持、已校验的场景开放交互。
3. 将 AI 输出限制为合法 JSON/白名单操作；实现解析、Schema 校验、几何验证、模板编译与降级兜底。
4. 首先让一种标准折叠题完成“拍照→题目解析→构型确认→3D 场景→动态测量”的完整闭环。

## 代码执行约束
- **先检查仓库现状**：技术栈、图片存储、路由、AI 调用、数据模型、现有测试。不重写旧功能。
- 优先以现有组件规范实施；若前端是 React，优先考虑 Three.js + React Three Fiber + drei；若非 React，根据现有框架选择适配方案。
- 模型只负责理解/规划，所有几何量由确定性数学代码计算；滑动帧内不得调用 LLM。
- 不得凭示意图比例推断题面未给出的数学事实；欠约束时必须提示示意构型，不得假称唯一解。
- 代码按照 scene、geometry、constraints、interactions、metrics、AI adapter 等职责模块化；提供运行说明。
- 完成每一阶段时列出实际修改文件、演示入口、测试命令、已实现功能与暂未实现项。

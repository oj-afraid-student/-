# 上传题目与通用 AI 学习页

入口：主导航「拍照学题」或 `/study`，几何实验室也有直达入口。

支持题目照片、手机拍照、文字输入；识别后编辑题干、条件和分问，人工确认后按分问录入思路并追问下一步。每问作答独立，切换分问清除旧提示。修改题干或条件撤销确认。修改分问会清空作答，避免错配。

UI 用可变数量的条件和分问适配题目；服务端只接收受限数据结构，不执行模型代码。模型不确定性显式展示。当前统一降级为文字学习，不把固定几何示例伪装成用户题目的模型；自动三维模板编译、全域验证和场景持久化仍待实现。

POST `/api/v1/ai/study` 使用现有真实会话、同源检查、1 MiB 请求限制和模型超时。recognize 接收 text 与可选 JPEG data URL；hint 接收用户确认后的 problem、分问索引、progress 与 followup。输入及输出均经 Zod 严格校验。照片复用作答转录预处理：15 MB 原图、最长边 1800、压缩后 950000 字符。照片和题目会发送到已配置模型服务，不写入数据库；页面刷新清空，尚无资料库或跨设备恢复。

运行依赖现有正式数据库和 ZHIXU_AI_* 配置。开发样例账号不能调用正式 AI 接口。
